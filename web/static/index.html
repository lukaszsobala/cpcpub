  3. 
      
    Or upload many machines at once
    
      
    
        With an account, the results of many machines go up together, as a
        batch:
      
    
      
      
        
    1. On each machine, run
          cpcpub --full --variants --json > NAME.json, one
          file per machine. --variants measures every build the
          machine can run; leave it out for the default build alone.
      2. 
        
    2. Bring the files together and join them:
          cat *.json > batch.json. Don't edit them: a result
          changed by hand is refused, and one refused result stops the whole
          batch.
      3. 
        
    3. Sign in, drop batch.json on the box above (or all the
          files at once, without joining them), give each machine a label, and
          upload. Or send it with the command below.
      4. 
      
    
      
    
      
    
        One machine's results become one upload when they sit next to each
        other in the file, which a file per machine always does. A result
        already on the hub is skipped, so sending a batch again after adding to
        it stores only what is new.
